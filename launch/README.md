# Launch materials

Drafts. Review before posting. Nothing goes public without your hand.

## Files

- [`show-hn.md`](./show-hn.md) — Hacker News post + your first comment
- [`reddit-ai-agents.md`](./reddit-ai-agents.md) — r/AI_Agents post
- [`mcp-discord.md`](./mcp-discord.md) — MCP community Discord announcement
- [`x-thread.md`](./x-thread.md) — X / Twitter launch thread (6 posts)

## Suggested cadence

Do NOT post everything at once. Space it out so each channel is fresh signal:

| Day | Channel | Why |
|---|---|---|
| 0 | Show HN | Highest-value single audience. Watch the thread for 4-6 hours. |
| +2 | r/AI_Agents | Different community, different angle (CI-first). |
| +4 | X / Twitter thread | Amplification. Best after HN / Reddit have surfaced any real quotes / feedback. |
| +7 | MCP Discord | Community that's already talking about the exact problem. Not a launch; a "hey, if you're scanning MCP configs, this might be interesting." |
| +14 | r/netsec | Only if the HN thread produced a good technical example / write-up. Otherwise skip. |

## Watch-list once posted

**Show HN specifically:** first 60 minutes decide the thread's ceiling. Reply
to every question. Don't argue. If someone points at a real grader bug or a
missing category, thank them and link to the issue templates.

**Metrics you actually care about:**

- Number of `uvx contextwall check` runs (opt-in telemetry, once you add it)
- GitHub stars going from 1 → something
- Number of grader-drift reports filed (highest-signal engagement)
- Number of people who reach out saying "would you talk about this for 20
  minutes" — that's the 5-conversation target from the 90-day plan

## What to avoid

- Overclaim ("state of the art detection") — you'll lose the thread
- Compare classifier accuracy against LlamaFirewall — you'll lose the thread
- Screenshots of dashboards you don't have
- Testimonials from people who haven't used it
- "Book a demo" as any CTA
